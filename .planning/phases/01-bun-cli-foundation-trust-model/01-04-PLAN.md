## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv -> app dispatcher | User command syntax becomes typed application requests. |
| Tool discovery facts -> terminal/docs | Local paths, versions, Bun runtime information, and exit statuses become visible output. |
| App dispatcher -> process adapter | The CLI triggers doctor discovery through the safe adapter created by Plan 03. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-13 | Repudiation | `src/cli/main.ts` | mitigate | Route invalid input, missing tools, and internal errors through named exit codes and document them in `docs/exit-codes.md`. |
| T-01-14 | Information Disclosure | `src/cli/render.ts` | mitigate | Render concise paths, versions, runtime versions, and capability statuses only; do not print full environment variables or unbounded stderr. |
| T-01-15 | Tampering | `src/cli/command.ts` | mitigate | Keep Phase 1 command syntax limited to default/help/doctor and reject unknown options through `ExitCode.invalidInput`. |
| T-01-16 | Spoofing | `docs/doctor.md` | mitigate | Document that PATH/version checks and `not-checked-yet` capability rows are not proof of full media capability readiness. |
</threat_model>

| Tool availability facts -> CLI diagnostics | Local executable paths and versions become user-visible diagnostic output. |

|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering / Elevation of Privilege | `src/domain/process-command.ts` | mitigate | Represent commands as executable plus argv array only; keep display strings diagnostics-only and test path edge cases. |
| T-01-05 | Repudiation | `src/domain/exit-codes.ts` | mitigate | Lock numeric exit values in unit tests so shell-visible behavior cannot drift silently. |
| T-01-06 | Spoofing | `src/domain/doctor-report.ts` | mitigate | Include resolved path fields only on available/check-failed tool facts so adapter output can report the executable actually found. |

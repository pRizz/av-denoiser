## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied media path → ffprobe argv | Path must appear as one argv token; no shell interpretation (TRUST-01 pattern). |
| FFprobe stdout → Zod | Untrusted JSON normalized into `MediaProbe` or typed parse errors. |
| stderr from ffprobe | May contain paths or filenames; treat as diagnostic text only; avoid logging verbatim to shared telemetry (CLI stderr is local). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | `createFfprobeJsonCommand` | mitigate | Flags are fixed string literals; only `executable` and `inputPath` vary from caller; input path is never interpolated into a shell string. |
| T-02-01-02 | Spoofing | Parser | mitigate | Zod boundary rejects malformed probes (`schema-mismatch`); no fallback “best guess” probe objects for required fields. |
| T-02-01-03 | Information Disclosure | Error messages | mitigate | Map failures to `FfprobeProbeError` kinds; do not echo full stdout on success path beyond parse; keep stderr snippets bounded in `non-zero-exit` (existing shape). |
| T-02-01-04 | Denial of Service | External probe | accept | Probe runtime/resource limits deferred to `ProcessCommand.timeoutMs` when callers set it; Phase 2 inspect caller may set bounded timeout in later hardening. |
